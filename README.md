## 🔧 Feature Engineering (Flight Price Prediction)

This repository also includes a **Flight Price Feature Engineering module**, created to practice and demonstrate core feature engineering techniques used in real-world machine learning workflows.

### Key Concepts Covered
- Handling missing values
- Encoding categorical variables
- Extracting time-based features (departure, arrival, duration)
- Feature transformation and scaling
- Preparing structured data for ML model training

This file focuses on building a **clean, model-ready dataset** and strengthening understanding of how feature engineering directly impacts model performance.
